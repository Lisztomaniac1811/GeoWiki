# Editable Reading Room dossier

The Reading Room is now an editing workspace, not a read-only mirror.

- Edit title, date, type, quality, relevance, tags, notes, quotes, saved source text, and primary attachment.
- Saved article/document text travels inside JSON and case.js, is searchable, appears in writing packets, and exports to Markdown.
- Attached local video is preferred as the primary player for video sources; YouTube/Vimeo remains an optional fallback.
- Return a source to the link mess or permanently delete it after confirmation.
- Edits persist in the Reading Room cache. When opened from Source Desk, they synchronize back immediately.
- **Save dossier** downloads an updated portable case and embeds available attachments within the existing size limits.
