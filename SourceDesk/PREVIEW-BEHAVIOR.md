# Preview behavior

- Publisher pages in the Reading Room are never loaded in an iframe. Use **Open original source** to read them in a normal browser tab.
- YouTube and direct Vimeo video URLs expose an optional player. It is not loaded automatically; use **Show video player** and **Close** to load or unload it.
- The Source Desk keeps an optional iframe for quick triage. Use **Show optional preview**; the Close control removes the iframe source completely.
- The Add Sources and Project Brief X/Cancel controls are explicit buttons and never submit their forms.
